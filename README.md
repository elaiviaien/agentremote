# ⚡ AgentRemote

**AgentRemote** — веб-оболонка (Web IDE) та локальний фоновий демон для віддаленого керування AI-агентами **Cursor** (та Antigravity / терміналом) на ваших комп'ютерах з будь-якого пристрою (комп'ютер, ноутбук, телефон).

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app)

---

## 🌟 Основні можливості

- **📱 Керування з будь-якого пристрою:** Повноцінний адаптивний Web IDE інтерфейс у браузері телефону, планшета чи ноутбука.
- **🤖 Cursor Agent CLI інтеграція:** Запуск промптів, стрімінг думок та коду (`stream-json`), візуалізація викликів інструментів (tools).
- **🔄 Продовження минулих чатів:** Повне збереження історії сесій та можливість продовжити будь-яку попередню бесіду через `cursor-agent --resume <id>` або `--continue`.
- **📁 Віддалений File Explorer:** Перегляд файлового дерева та вмісту файлів на машині.
- **⚡ Віддалений термінал:** Виконання PowerShell / Bash команд напряму на підключеному комп'ютері.
- **☁️ Серверлесс & Низьке споживання RAM:** Оптимізований бекенд на **Fastify + WebSockets** зі споживанням **~35-45 MB RAM** на Railway.
- **🔒 Захищений доступ:** Вхід за логіном і паролем (JWT + bcrypt), зв'язок воркерів через секретний токен.

---

## 🏗️ Архітектура

```
[ 📱 Телефон / Браузер ]
          │  (HTTPS / WSS з JWT)
          ▼
[ ☁️ Railway Cloud Hub ]  <-- Fastify + WebSockets (< 45MB RAM)
          ▲
          │  (Persistent WSS з Worker Token)
[ 🖥️ Local Daemon ]      <-- Працює на вашому ПК / Ноутбуку
          │
          ▼
[ 🤖 Cursor Agent CLI ]   <-- Створення/продовження чатів, виконання завдань
```

## 🚀 Швидкий старт

### 1. Деплой Cloud Hub на Railway
Сервер розгортається автоматично за допомогою Dockerfile / Nixpacks.

Змінні середовища (`Environment Variables`):
| Змінна | Опис | За замовчуванням |
|---|---|---|
| `ADMIN_USERNAME` | Логін для входу у веб-інтерфейс | `admin` |
| `ADMIN_PASSWORD` | Пароль для входу | `admin123` |
| `JWT_SECRET` | Секретний ключ підпису токенів | (рандомний рядок) |
| `MASTER_WORKER_KEY` | Токен підключення локальних машин | `agentremote-worker-secret-key-2026` |
| `PORT` | Порт сервера | `3000` |

---

### 2. Запуск локального демона на вашому комп'ютері (Worker)

1. Склонуйте репозиторій або завантажте проект:
```bash
git clone https://github.com/elaiviaien/agentremote.git
cd agentremote
npm install
```

2. Налаштуйте файл `.env`:
```env
HUB_URL=https://your-railway-app.up.railway.app
WORKER_TOKEN=agentremote-worker-secret-key-2026
DEVICE_NAME=My-Work-PC
DEFAULT_WORKSPACE=C:\Users\YourUser\Projects
```

3. Запустіть воркер:
```bash
npm run worker
```

Демон автоматично:
- Знайде встановлений `cursor-agent` CLI у системі.
- Підключиться до вашого хмарного хабу на Railway.
- Повідомить про готовність до виконання завдань.

## 📱 Як користуватись з телефона

1. Відкрийте URL вашого сервера на Railway у мобільному браузері (Safari / Chrome).
2. Введіть логін та пароль.
3. Оберіть активну машину та відкрийте існуючий або новий чат Cursor.
4. Напишіть задачу — агент на вашому комп'ютері почне писати код у реальному часі!
